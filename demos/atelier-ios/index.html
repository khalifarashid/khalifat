Commerce / Interaction study

Retail, stripped back to the object.

A storefront for pieces that carry no name — only a designation, a material and a price. Titanium-dark ground, one thread of iridescence, and motion that carries you between screens rather than cutting to them. Drive it below, or tap straight into a screen.

Shared element
Tapping a card lifts that object into the detail hero and back again — the same element, measured and re-flowed, never a cross-fade.
Layered push
The outgoing screen recedes, desaturates into blur and gives up 4% of its scale while the incoming one slides over it.
Add to bag
The pill washes with the accent gradient, collapses to a tick, and throws a copy of the object into the bag icon.
Material swap
Colourways tween the render itself through registered custom properties, so the object changes finish instead of swapping picture.
Reduced motion
Every transition above collapses to an instant state change when the system asks for it.
